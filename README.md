[Material UI](https://mui.com/material-ui/) 是一个全面的 React 组件库，它独立实现了 Google 的 [Material Design](https://m2.material.io/design/introduction/) 设计系统。
它受到全球众多顶尖产品团队的信赖，经过数千名开源贡献者十余年的严格实战检验。

Material UI 的核心功能由 [MUI X](https://github.com/mui/mui-x) 扩展，这是一套用于高级用例的复杂组件。
